# mania8522191

Illustration portfolio of mania8522191: pixiv works with process timelapses, FF47 goods, and a solo-developed indie card game.

Live site: https://mania8522191.github.io

## Layout

- `index.html`: the page markup. It loads `site.css` and `site.js`.
- `css/`, `js/`: the styles and scripts, one file per part of the site. `tools/build.py` joins them into `site.css` and `site.js`. `js/data.js` holds the works, goods and art books, one per line.
- `img/`: pictures.
- `tools/`: scripts that make the pictures and check the site; `tools/README.md` explains how to add a work or an art book (in Chinese).
